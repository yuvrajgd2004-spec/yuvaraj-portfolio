# Yuvaraj GD - Personal Portfolio Website

A modern, colorful, and fully responsive personal portfolio website built with React, TypeScript, and Vite. This portfolio showcases professional experience, projects, skills, and achievements in a clean and recruiter-friendly format.

## 🚀 Features

- **Modern Design**: Clean, minimalistic UI with colorful gradients (blue/teal/purple accents)
- **Fully Responsive**: Optimized for mobile, tablet, and desktop devices
- **Smooth Animations**: Framer Motion powered animations and micro-interactions
- **Type-Safe**: Built with TypeScript for better code quality
- **Fast Development**: Vite for lightning-fast HMR and builds
- **Component-Based**: Modular architecture using React components
- **Accessible**: Semantic HTML and proper ARIA labels
- **SEO-Friendly**: Optimized meta tags and semantic structure

## 🛠️ Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **shadcn/ui** - UI component library
- **Radix UI** - Accessible component primitives
- **Lucide React** - Icon library

## 📦 Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```

## 🎨 Sections

1. **Hero** - Introduction with name, role, and CTAs
2. **About** - Professional summary and highlights
3. **Skills** - Categorized skills (Business, Technical, Soft)
4. **Experience** - Timeline of professional roles
5. **Projects** - Featured projects (Narrator's BI, GreenVolt)
6. **Education** - Academic background, certifications, languages
7. **Contact** - Contact information and form

## 🎯 Customization

To customize the portfolio with your own information:

1. Update personal details in each component file
2. Modify colors in `tailwind.config.js` and `src/index.css`
3. Replace placeholder contact information in `Contact.tsx`
4. Update project details in `Projects.tsx`
5. Adjust animations and transitions as needed
